FONTFORGEPRO · ABOUT

FontForgePro

一个以原生 FontForge 为内核的 Windows 字体设计应用。 保留 FontForge 的全部专业功能，加上中文界面、深色外观和少量 FFpro 工作流工具。

打开本地教程 查看许可

版本

FontForgePro2.4.0
FontForge 内核20251009（2025-10-09 构建）
Python3.12（随 FontForge 提供）
平台Windows 10 / 11 64 位
界面语言跟随系统；中文系统显示中文

功能

FontForge 全部功能

字形绘制、节点编辑、Spiro、布尔运算、组件、锚点、连字、字距、OpenType 特性、多母版、变量字体、hinting、验证、脚本。

FFpro 工具

字体体检、字体预览、补齐基本字符集、字形清理、水平居中、圆角拐点、模板字体、中文教程、官方手册。

字体预览

临时导出 WOFF2，在浏览器里用可编辑文字查看 12–144 px 八档字号、段落排版和深浅色效果；文字自动保存，一键保存不需要改文件名。

完整官方手册

FontForge 20251009 官方文档已离线镜像，约 700 个页面，带中文导航和本地搜索。

多语言

跟随 Windows 显示语言，支持中文、英文、法文、俄文、西班牙文和阿拉伯文（部分），以及 FontForge 自带的德文、日文、韩文等。可手动切换。

现代外观

深色单色主题、圆角控件、FFpro 启动画面；布局仍是 FontForge 原生布局，功能不缩水。

新手引导

第一次打开显示四步引导，可随时跳过；之后可从 FFpro 工具菜单重新打开。界面按系统 DPI 自动放大，菜单、对话框和字体窗口保持清晰。

中文字体兜底

中文界面优先使用微软雅黑，系统没有中文字体时使用内置的 Noto Sans SC（SIL OFL 1.1），避免方框和乱码。

Windows ARM64

提供 ARM64 兼容包，通过 Windows 11 x64 仿真运行；原生 ARM64 需等待上游 FontForge 的 ARM64 构建。

本地优先

不联网、不上传字体。教程、预览页和关于页都是本地 HTML。

深色界面

字体网格、字形画布、菜单和对话框统一为黑/白单色外观，长时间编辑更舒服。
