鼠标键位标签 Mse1 / Mse2

工具栏下方的四个小图标是你为鼠标按键分配的工具，名字来自 FontForge 的内部缩写：

Mse1鼠标左键当前工具。
^Mse1Ctrl + 鼠标左键当前工具。
Mse2鼠标右键当前工具。
^Mse2Ctrl + 鼠标右键当前工具。

把鼠标停在工具栏图标上约 0.25 秒，会显示该工具的完整名称和快捷键；名称来自 FontForge 的中文翻译。

网格模式

字形窗口默认已经打开网格。左侧图层栏里的 # 复选框就是网格显示开关：

  • # 勾选：显示坐标网格和辅助线；取消勾选：隐藏网格。
  • CB：显示/隐藏背景层；CF：显示/隐藏前景层。
  • 底部的 - / +：缩小 / 放大画布。
  • 要做 TrueType 像素级网格适配，用 视图 → Grid Fit → Show Grid Fit…（或 Ctrl+Shift+#）。

如果看不到网格：确认 # 已勾选、缩放不要太小；网格线颜色可以在 文件 → 首选项 → 外观 里调整。

按不同字号预览当前字体 / 当前字形

在字体窗口或字形窗口打开 工具 → FFpro 工具：

  • 字体预览（多字号）…：导出当前字体，在本地页面里按 12、16、24、32、48、64、96、144 px 八档字号显示，文字可编辑并自动保存。
  • 当前字形预览（多字号）…：只显示当前字形在八档字号下的效果，适合检查某个字母、汉字或符号的比例。

调整画线粗细

  • 绘制前：双击工具栏里的自由绘制图标，设置笔触宽度、端点和连接方式，再画线。
  • 绘制后：选中用钢笔/曲线工具画出的开放路径，打开 FFpro 工具 → 线条粗细…，输入字体单位宽度（例如 40），即可把路径加粗成轮廓。
  • 线条粗细只处理开放路径；已经闭合的填充字形会被跳过，避免破坏原有轮廓。需要整体加粗字形时，用 FontForge 的 元素 → 样式 → 加粗 或 更改字重。
