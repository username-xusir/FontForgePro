FONTFORGEPRO · 本地手册

用 FontForge 的全部能力，
做一套自己的字体。

FontForgePro 以原生 FontForge 20251009 为内核，保留它的全部专业功能， 并在 工具 → FFpro 工具 中加入少量更顺手的整理、圆角、居中和模板功能。 这份教程不需要联网，随时可以从菜单重新打开。

5 分钟上手

如果你只想先做出一个能安装的字体，按下面四步走即可。

  1. 新建字体。在字体窗口按 Ctrl+N，或从 文件 → 新建 开始。想省事可以直接用 工具 → FFpro 工具 → 打开模板字体，模板已经准备好常用字符槽位和宽度。
  2. 打开一个字形的编辑窗口。在字体网格里双击任意字母，进入字形视图。画布中央是基线，左侧竖线是原点，右侧竖线是字符宽度。
  3. 画轮廓。用工具栏的钢笔工具点出节点，或直接用矩形/椭圆工具画基本形。轮廓必须是闭合的，内部挖空要用相反方向的轮廓或布尔运算。
  4. 导出。回到字体窗口，文件 → 生成字体（Ctrl+Shift+G），选择 TrueType 或 OpenType，保存为 .ttf / .otf。要网页字体就再导出 WOFF2。

先存盘。FontForge 的原生工程格式是 .sfd。养成 Ctrl+S 的习惯；导出 .ttf 前也建议先保存 .sfd，方便以后继续改。

界面地图

FontForge 的窗口分工很清楚，先认住三类窗口就不会迷路。

字体窗口（Font View）

看到所有字符格子的地方。双击进入字形；右键可以查看字形信息、复制、删除、添加编码。菜单里的批量操作大多在这里执行。

字形窗口（Glyph View）

真正画字的地方。左侧工具栏、上方标尺、中间轮廓、右侧图层面板。每个字形有前景层和背景层，背景层适合放参考图或临摹底稿。

度量窗口（Metrics View）

调字距和连字的地方。可以同时看到多个字形，拖动字符之间的间距，或编辑 kerning 对。

字体窗口顶部的信息条

显示当前字体名、Em 大小、字形数量、选中数量。双击信息条可以打开字体信息对话框，改家族名、样式名、版本、版权、上下伸、下划线位置等。

图层面板

字形窗口右侧的图层列表可以切换前景/背景，也能新建图层。多层字体（比如彩色字体、变量字体）会在这里出现多个层。眼睛图标控制可见性，锁图标控制是否可编辑。

中文界面：FontForgePro 会根据 Windows 系统语言自动选择中文或英文界面。中文界面使用微软雅黑作为 UI 字体，不会出现方框乱码。

绘制字形

钢笔与节点

钢笔工具每点一下添加一个角点；按住拖动会拉出控制柄，变成曲线点。闭合轮廓时点回第一个节点，或按 Enter。开放的路径在导出时会被忽略或产生意外结果，正式字形尽量保持闭合。

矩形、椭圆与多边形

工具栏里的矩形/椭圆工具可以直接拖出形状。FontForge 还提供星形、螺旋等工具。画完后用指针工具 V 选中节点继续调整。

Spiro

Spiro 是一种用曲率控制的平滑曲线模式，适合做圆润的几何字形。工具栏的 Spiro 按钮可以切换。Spiro 轮廓在导出前可以转成普通三次曲线。

背景层

把参考图拖进字形窗口，或使用 文件 → 导入，图片会进入背景层。背景层不会被导出，只用于描摹。也可以在背景层画辅助线。

坐标与基线

字体单位通常是 1000 或 2048。基线 y=0，上伸约 800，下伸约 -200。不同字形共享同一套坐标。

字符宽度

右侧宽度线决定 advance width。字母通常 500–700，空格 250 左右。宽度为 0 的组合字符不会前进。

参考线

可以在字形窗口显示基线、x 高度、大写高度、斜体线等。视图菜单里可以开关。

节点编辑

这是字体设计最常用的操作。FontForge 的节点比普通矢量软件多一层“曲线类型”的概念。

选择与移动

  • 指针工具 V 框选节点，或按住 Shift 点选多个。
  • 方向键微移 1 单位，Shift+方向键移动 10 单位。
  • 拖动控制柄改变曲线；按住 Alt 可以单独调整一侧手柄。

角点、曲线点、切线点

右键节点可以切换类型：

类型特点适用
角点（Corner）两侧手柄独立，轮廓在这里形成尖角字母的尖角、衬线端点
曲线点（Curve）两侧手柄共线，但长度可以不同大多数平滑转折
切线点（Tangent）手柄共线且等长，曲线最平滑圆弧、碗形结构
HV 曲线点手柄水平/垂直约束需要保持水平或垂直的曲线

添加与删除

在轮廓上双击可以插入节点；选中节点按 Delete 删除。删除后轮廓会自动连接。要断开轮廓，用剪刀工具在节点处剪开。

对齐与变换

选中多个节点后，可以用 元素 → 变换 做旋转、缩放、倾斜、翻转；也可以用 元素 → 对齐 做水平/垂直对齐。数值变换在 元素 → 变换 → 数值变换 里输入精确值。

FFpro 小工具：如果只是想把字形在宽度里居中，用 工具 → FFpro 工具 → 水平居中，比手动算左右边距快。

路径与布尔

布尔运算

选中两个或多个重叠轮廓，使用 元素 → 重叠 → 并集 / 差集 / 交集 / 异或。做字母的内部挖空（比如 O、B、e）时，最稳的方法是画外轮廓和内轮廓，然后执行“差集”或“移除重叠”。

移除重叠

元素 → 重叠 → 移除重叠 会合并所有相交轮廓，自动处理方向。导出前建议执行一次，避免填充规则问题。

简化与清理

元素 → 简化 → 简化 可以减少节点；添加极值点 在曲线的最高/最低/最左/最右处补点，让栅格化和 hinting 更稳定；坐标取整 把浮点坐标变成整数。

这一组操作可以一次完成：工具 → FFpro 工具 → 字形清理，会对选中字形（或全部字形）执行坐标取整、补极值点、统一轮廓方向。

圆角拐点

工具 → FFpro 工具 → 圆角拐点… 可以把尖角变成圆弧，半径以字体单位计算。它只处理相邻两边都是直线的角，曲线拐点保持原样。适合做圆润的几何风格字体。

描边与扩展

元素 → 扩展描边 可以把细线轮廓变成有宽度的形状。做等线体、装饰线时很有用。

组件、连字与排版

引用（组件）

在字形窗口里 编辑 → 复制 一个字形，然后在另一个字形里 编辑 → 粘贴为引用，就能建立组件关系。改基础字形，所有引用会一起更新。带重音的字母（á、ö）通常这样搭。

锚点与 mark 定位

用锚点工具在基础字母上放 top、bottom 锚点，在重音符号上放对应锚点，然后在字体信息里建立 mark 特性。FontForge 会自动生成 mark-to-base 定位。

连字

在字体窗口打开 元素 → 字体信息 → 查找，新建 liga 或 dlig 查找，把 f + i 映射到 fi 字形。也可以在 元素 → 连字 里可视化编辑。

字距与 kerning

打开 窗口 → 度量，选择两个字形，拖动它们之间的间距。FontForge 会记录 kerning 对。成对调整很多字母时，可以先用类别（class）批量处理。

OpenType 特性

字体信息里的 GSUB/GPOS 面板支持连字、替代、小型大写、旧式数字、分数、上下标等。所有表都可以手动编辑，也可以从特性文件（.fea）导入。

变量字体与多母版

FontForge 支持多母版（MM）和设计空间文件。用 文件 → 新建 → 多母版 或打开 designspace 工程，可以制作可变字体。

字体预览

FontForge 的字体视图本身就会显示字形缩略图，但设计时经常需要看整段文字在不同字号下的效果。FFpro 增加了一个独立的浏览器预览：

  1. 在字体窗口或任意字形窗口打开 工具 → FFpro 工具 → 字体预览…。
  2. FontForgePro 会把当前字体临时导出为 WOFF2（如果失败会自动退回 TTF/OTF），写到一个临时目录，不会修改你的工程文件。
  3. 浏览器会打开预览页。你可以在文本框里输入任意示例文字，页面会同时显示 12、16、24、32、48、64、96、144 px 八档字号，也可以切换深色/浅色。
  4. 预览页底部的“段落排版”会显示 18px、1.85 行高的正文效果，适合检查中文长文的阅读感。

预览用的是导出后的字体，所以看到的效果和安装/导出后的效果一致；如果字体缺少某些字符，浏览器会用系统字体回退显示。大字体（例如几万个字形的 CJK 字体）生成 WOFF2 时会多等一会儿，生成完成后浏览器才会打开。

如果你需要 FontForge 原始界面里的预览方式，也可以使用字体视图的字号切换、字形视图的填充预览，以及 窗口 → 新建度量视图 同时查看多个字形。

导出与验证

生成字体

  1. 先保存工程。Ctrl+S 保存 .sfd。
  2. 补字体信息。家族名、样式名、版本、版权、上下伸、下划线位置。名字不要和系统已有字体冲突。
  3. 清理轮廓。移除重叠、补极值点、统一方向。FFpro 的“字形清理”可以一次完成后面两项。
  4. 生成。文件 → 生成字体，选择 TrueType（.ttf）、OpenType（.otf）、WOFF、WOFF2 等格式。需要网页用就再生成 WOFF2。
  5. 验证。用 元素 → 验证 检查轮廓方向、开放路径、自交等问题；也可以在字体窗口用 视图 → 显示 查看填充效果。

安装测试

双击生成的字体文件，选择“安装”，然后在文字处理软件里输入一段话看看。重点检查：字母间距、标点位置、上下伸是否被裁切、粗体/斜体是否有对应文件。

网页字体

WOFF2 体积最小，现代浏览器都支持。导出后在 CSS 里用 @font-face 引入即可。注意网页字体通常只包含你实际用到的字符集，可以先用子集化工具裁剪。

常见问题

为什么界面里有方框或乱码？

FontForgePro 已经把 UI 字体设为微软雅黑，正常不会出现。如果仍然出现，检查 %APPDATA%\FontForgePro\FontForge\prefs 里的 ResourceFile 是否指向应用目录下的 resources\ffpro.resources。

为什么打开字体后是英文？

界面语言跟随 Windows 系统语言。系统是中文时启动器会设置 LANG=zh_CN。如果系统是英文，FontForge 会使用英文界面。

设置和最近打开的文件在哪里？

在 %APPDATA%\FontForgePro\。FontForge 的偏好、自动保存、插件配置都在里面的 FontForge 子目录。卸载应用不会自动删除这个目录，方便保留设置。

FFpro 工具菜单在哪里？

字体窗口或字形窗口的 工具 菜单底部，名为 FFpro 工具。如果看不到，检查 文件 → 配置插件 里 FFpro 是否启用。

能写 Python 脚本吗？

可以。FontForge 自带 Python 3.12，支持 fontforge 和 psMat 模块。用 文件 → 执行脚本 运行，或把脚本放到用户脚本目录。插件本身也是 Python 写的，源码在应用目录的 lib\python3.12\site-packages\ffpro_tools.py。

为什么圆角只对部分角生效？

圆角命令只处理相邻两段都是直线的尖角。曲线与直线相接、或两个曲线相接的拐点会保持原样，避免破坏原本的曲线形状。

和原来的 FontForge 有什么区别？

内核、功能和文件格式完全一致；区别是品牌、中文 UI 字体、深色外观、FFpro 工具菜单、模板字体和这份本地教程。你可以随时用原版 FontForge 打开 FontForgePro 保存的 .sfd。

支持哪些系统？

当前发布包是 Windows 64 位。FontForge 本身跨平台，macOS 和 Linux 用户可以自行编译，或使用原版 FontForge 加同一套插件。
