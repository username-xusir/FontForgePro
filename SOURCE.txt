FontForgePro 2.4.0 — Corresponding Source
=========================================

This package includes the source code for the FontForgePro-specific parts:

  source\
    src\Launcher.cs              Windows launcher / branding / locale / DPI source
    src\WelcomeForm.cs           First-run guide source
    src\fontforge.manifest       DPI-awareness manifest for the FontForge kernel
    src\patch-manifest.ps1       Updates the embedded RT_MANIFEST resource
    src\make_resources.py        Generates the FontForge appearance resource
    src\build_ar_catalog.py      Builds the partial Arabic UI catalog
    ffpro_tools.py               FFpro Python plugin for FontForge
    ffpro.resources              Generated modern FontForge appearance resource
    ffpro-ar.resources           Arabic variant using Segoe UI
    ffpro-splash.png             FFpro splash image
    NotoSansSC-OFL.txt           SIL OFL 1.1 license for the bundled UI font
    locale\ar\LC_MESSAGES\FontForge.mo   Partial Arabic catalog
    FFpro-Starter.sfd            Starter font template
    build.ps1, build-arm64.ps1, install.ps1, uninstall.ps1
    ARM64.md, README-ARM64.txt
    README.md
