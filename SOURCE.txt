FontForgePro 2.1.0 — Corresponding Source
=========================================

This package includes the source code for the FontForgePro-specific parts:

  source\
    src\Launcher.cs              Windows launcher / branding source
    src\make_resources.py        Generates the FontForge appearance resource
    ffpro_tools.py               FFpro Python plugin for FontForge
    ffpro.resources              Generated FontForge appearance resource
    FFpro-Starter.sfd            Starter font template
    build.ps1, install.ps1, uninstall.ps1
    README.md

The Chinese manual, preview template, and Chinese navigation for the official
documentation are under:

  help\index.html
  help\about.html
  help\official.html
  help\preview-template.html
  help\style.css

  help\fontforge-docs\
